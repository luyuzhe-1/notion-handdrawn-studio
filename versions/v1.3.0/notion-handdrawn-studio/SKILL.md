# Notion 黑白手绘工作室

创作干净、克制、有轻微趣味的原创图片。画风保持一致，人物与物件依据当前内容变化。默认黑白、无文字；用户明确要求的文字、颜色、人物、比例和目的优先。参考的是视觉语言，不把官网人物、构图或图标作为原创结果复用。

## 判断用途与交付

- **内容配图**：正文、段落或观点。先理解核心意思，找到适合图像表达的动作、状态或关系；按文章版式安排构图。不平均给每段配图，也不默认固定张数或 16:9。
- **独立插画／小装饰**：从想法直接构思人物、物件、动物或场景。人物不是必需，默认没有固定主角；透明元素可用于正文、页面或贴纸。
- **Logo**：重点创作图形标志，可搭配用户给出的名称。先压缩外形与识别点，再检查单色和小尺寸；完整品牌系统或字体设计不自动扩展。
- **已有图编辑**：先查看目标，按用户指定范围编辑，保留已确定的主体、文字、动作与背景等未修改部分。

用户只要规划或提示词时，止于所要求的交付。用户明确要生成时，直接生成；不额外增加“先确认方案”的关卡。关键内容缺失且无法推断时才简短询问；明确不影响结果的细节按默认值处理。

## 按需读取参考

每次读取 [画风与参考选择](references/style-guide.md)。再按当前用途读 [内容配图](references/content-illustration.md)、[独立插画与装饰](references/standalone-illustration.md) 或 [Logo](references/logo-design.md)；不要同时载入全部模式。

[提示词构建](references/prompt-building.md) 用于组织生成／编辑提示词，[检查与修订](references/quality-review.md) 用于检查结果。验证 skill 时才读取 [验证说明](validation/README.md) 和案例集，普通创作不加载验证材料。

## 工作方式

1. 从请求确定用途、核心意思、必须保留的元素、文字、比例与背景。内容配图记录对应段落；模糊创意选一个清楚的关系即可，不额外发明品牌故事或宣传文案。
2. 从参考索引选与用途匹配的少量图片，通常 1–2 张；必要时再补一张。先查看本地预览，区分原图编辑目标与风格参考。无需每次联网或加载整个原始库。
3. 有人物时读取提示词构建中的「人物造型基准」，先确定宽缓大形，再附短主题与动作段；跨主题沿用此基准，不临时堆叠写实描写。非人物按对应用途构建紧凑提示词。
4. 位图生成与编辑默认用内置 `image_gen`。新图参考输入遵守工具规则：工具要求省略图片参数时，先查看参考再转述为文字，记录实际输入方式；不可把新主题伪装成编辑。编辑时区分目标图与风格参考。多张不同图片分别生成。透明请求设置真实透明背景，不用白底或棋盘格代替。工具不可用时说明限制，不伪称已生成，也不自行切换收费 API。
5. 查看真实输出，按用途检查。人物必须分别检查外轮廓抽象程度、内部细节和动作接触；任何一项明显偏离就记录需要调整，不能用主体正确或透明合格抵消风格失败。实际可读取文件时验证透明通道、尺寸和 Logo 缩略效果；不可读取时说明哪些项未核实。一个具体缺陷可作一次针对性编辑并复查。相同问题仍未解决时保留结果和记录交给用户，不无限重试。
6. 在用户指定目录或当前工作区保存最终图与简短生成记录，保留使用的提示词、参考 ID、用途与已知问题。已有文件默认另存版本。交付图片预览、文件路径和精简检查结论；小图标栅格结果不宣称是可编辑矢量文件。

## 稳定的默认值

干净连贯但略不规则的墨线，简化五官，姿态清楚，适量黑色实面，无固定角色。人物以柔和的长曲线、概括的肢体外形和黑白块面表达；肘膝用简洁转向交代，内部线只保留动作与遮挡必需的部分，具体取舍见画风指南的“人物减法”；小图标可更粗、更少细节。趣味来自一个动作或关系，留白由用途与版式决定。正文场景通常白底，独立人物、小装饰与图形 Logo 默认透明底。局部网点、简化实黑投影、点缀色和短标签是按需选项，不是每次必带的元素。
