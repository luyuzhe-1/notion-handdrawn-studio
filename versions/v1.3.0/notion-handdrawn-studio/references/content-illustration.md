# 内容配图

读懂文字后，选一个能帮助理解或感受内容的核心意思：动作、状态、对比或关系。无需每张都解释流程，也允许无人物。

## 规划

只要求规划时，给足以做决定的少量建议：放在何处、表达什么、主体动作或关系、构图／背景建议。按内容价值选配图点，不给固定 4–8 张，不把文章拆成平均配图的章节。用户规定数量时遵循。

## 构思

让抽象内容落在可读的视觉动作上，物件与动作应对应原意。不要看到“成长”就机械套用植物、看到“灵感”就机械套用灯泡。若一幅图需要长篇解释才成立，简化关系。

两个人或多个物件可以表达协作，但人物不能只是站在角落。没有人物的物件关系也可成立。不要默认固定主角或荒诞机械流水线。

## 布局与生成

正文场景通常干净白底。没有比例要求时按场景选择横版或方形；嵌入明确版式时适配版式。需要文字空间时再指定相应留白，否则不任意把主体偏到一侧。

默认不加标题、标注与箭头。必要的短标签遵循用户原文，文字不替代图像本身的表达。若明确要求多图，记录每张对应的段落与意思，各自生成，保持共享画风但让构图随内容变化。
