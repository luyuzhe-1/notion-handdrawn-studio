# 画风与参考选择

## 来源与目标

本 skill 的基线来自 2026-10-11 对 Notion 官网公开素材的归类研究；它是用户选择的创作方向，不是 Notion 官方设计规范。原始库有 93 份插画文件，本 skill 只携带 12 份重点参考。完整溯源见 [visual-index.json](visual-index.json)。原文件与白底预览分开保存；预览用于看清透明墨线。

官网存在人物、头像、小图标、圆脸角色、彩色功能图等分支。这里默认使用黑白人物和轻量物件：不要把全部分支混成一套固定构图。低分辨率边缘锯齿不是必须模拟的笔触。

## 共同语法

- 连贯的墨线，自然弯曲、轻微不对称；不反复描摹成草稿乱线。人物的内部五官与衣纹轻一些，小图标的外形可更粗。
- 五官简化，动作能读懂，手与道具关系成立。不同发型、体态、衣服与姿势共享这套语法，不固定“小黑”或其他主角。
- 线稿与少量黑色实面形成节奏。头发、裤子、背面或道具可用实黑，但不要求每个人物都有黑发。
- 默认只用黑与透明／白。墨线抗锯齿形成的边缘灰度正常；用户未要求时不使用大面积灰色填充、彩底、光影渐变。
- 元素少但关系清楚。黑面用于层级，留白按版式与用途安排，不强制一个白色像素百分比。
- 幽默温和，来自姿态、尺度或物件之间的小转折；不要自动加星星、花、灯泡、箭头或圆形徽章。

## 人物减法

人物默认比 v1 初次样例更简练。此偏好适用于独立人物和内容配图中的人物；Logo 与独立小装饰沿用各自规则。用户明确要求更细致的肖像、衣物或手势时，按请求保留必要细节。

- 先让整体轮廓、身体倾斜、视线和手与道具的接触交代动作，再决定是否需要内部线。
- 从少量宽缓的平面大形开始组织躯干、袖子与腿；衣服和身体共同构成轮廓，不先画出写实人体再删细节。具体提示词使用[人物造型基准](prompt-building.md#人物造型基准)，不把这里的全部观察逐条重复进生图提示。
- 肢体先概括成有方向的整体形状：手臂与袖子用连贯的长弧线，腿与裤子用简洁长形或黑色块面；肩、肘、膝以宽缓转向连接，不逐段强调肌肉、关节鼓包或解剖起伏。需要弯折时保留清楚的弯曲方向，不把所有转角都磨成圆弧。
- 允许为动作做轻微的长度、宽度和比例概括；身体仍有支撑与重心。保留胳膊与躯干、两腿之间必要的空隙，让简化后的姿态仍可读。柔和指轮廓走势，不是模糊边缘、淡灰线或柔光。
- 衣服以完整的大轮廓为主。只在关节转折或遮挡不清处留短线；省去重复褶皱、装饰缝线与布料体积描写。
- 手先看作一个小掌形或扁平的手套形，随动作保留拇指、指向手指或少量并拢指线；腕部简单连接。操作电脑、握壶、指书时保留接触关系，不逐根描绘指节，也不把具体手势统一成圆团。
- 鞋或袜子概括为小楔形、豆形或短弧轮廓，方向清楚即可；省略脚踝骨点、鞋带、鞋底分层和褶纹。不要靠画完整脚掌解剖解释落脚。
- 头发用一两个清楚的整体形状组织，少画碎发和发丝。五官用点眼、简短鼻口表达，避免用大眼、高光或复杂表情制造可爱感。
- 允许轻微不对称与自然弯曲，保持干净。手绘感来自形体与线条的自然偏差，不靠噪点、抖线或细节堆叠。

以使用尺寸检查：删掉一条内部线后若不影响姿态、接触或遮挡的理解，就倾向省略。不要给所有人物硬性规定线条数量，也不要把“简化”变成粗描边、幼儿比例或省掉关键部位。

### 从官网人物观察到的形体取舍

C296 的抬起手臂以长弧线交代抬举方向，黑裤和小鞋用很少的形体信息表达站立；C293 中弯曲的袖子、裤腿与躯干是概括的大形，靠倾斜、开口和接触表现动作；C294 的手仍有必要指线，说明抽象不等于把所有手指都删除。这些是所选参考的观察，不是所有官网人物统一的硬性规范。

当已有图片的轮廓仍偏写实时，仅删内部线不会完成形体简化。用户要求抽象化肢体时，应允许重塑相关人物外轮廓与局部比例，保留的是动作意图、支撑、接触和构图；不要同时把待修改的解剖轮廓锁死。

## 可选项

局部衣料网点、坐垫网点、简化实黑投影、一个点缀色、轻微超现实与短文字，都按主题或明确要求选用。默认不加纸张纹理、全图颗粒、水彩洗染、柔光渐变、写实阴影或粗糙笔刷。网点不是“手绘感”的必需品，也不因某张参考有网点就遍布新图。
