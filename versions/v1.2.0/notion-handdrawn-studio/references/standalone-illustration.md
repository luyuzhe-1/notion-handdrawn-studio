# 独立插画与小装饰

## 人物或场景

从用户想法选一个清楚动作，先让姿态、视线与道具关系成立，再用发型、衣着与体态建立个性。人物五官克制，身体不必写实，但手脚与物件要合理。默认无需固定年龄、性别、职业或人物身份。

主体是物件或动物时可完全不画人物。轻微拟人或超现实可以有趣，但不必每件物品都加点眼。用户给出明确主体时不任意补配角与道具。

## 小装饰

先判断使用位置和识别点：一朵花、一只动物、一个手势、少量线条或一个小物件就足够。线条可以比人物更粗，内部细节要少。只有用户要求边缘互动时才裁出探头或跨边缘的构图；全身元素保留全部关键部位。

默认透明底。保留合理空边，避免与画布边缘相切；不额外铺白色底片、贴纸描边、棋盘格或圆形徽章。场景类独立插画可根据使用目的选择白底，用户背景要求优先。

## 系列

系列维持线重层级、五官简化程度和黑白关系。用户要不同人物时变化身份与动作；要同一人物时保持身份。不把系列自动拼成一张联系表，除非用户明确要合集预览。
